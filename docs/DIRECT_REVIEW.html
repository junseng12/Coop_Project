tail -f 화면에서 Ctrl+C는 로그 보기만 종료합니다. 실행 중인 실험은 계속됩니다. RUNNING은 진행 중, EXIT_CODE=0은 완료, 그 외 값은 실패입니다.

자동 수행 범위

호스트 메모리 확인 → 기존 백엔드 기동 → 로컬 EVerest Compose 기동 → 새 PnC 모의 충전 약 45초 → 종료 → 새 거래와 CDR·청구서 연결 확인 → 인증 응답·세션 로그·계량·청구 계산 대조 → result.html 저장 순서입니다. 실행 로그는 단계별로 남습니다.

결과를 읽는 방법

result.html의 통과는 별도 PnC 증거 검사와 delivery gate가 모두 통과한 경우입니다. 이번 거래 ID·충전량·모의 청구액 및 각 확인 항목이 함께 표시됩니다. delivery.json 자체의 PnC false는 API 상관관계 검사 범위를 뜻하며, review-summary.json에서 별도 PnC 증거를 확인합니다. 실제 결제나 물리 계량 검증을 뜻하지 않습니다.

구성과 보존
